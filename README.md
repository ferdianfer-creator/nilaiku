# NILAIKU - Sistem Informasi & Pelacakan Nilai Siswa
### SMP Islam Al Azhar 30 Tasikmalaya
Tahun Ajaran 2026/2027

Aplikasi web & mobile (PWA) untuk pelacakan nilai siswa secara real-time, terintegrasi dengan database cloud **Supabase** dan multi-kelas.

---

## 🚀 Fitur Utama
1. **Portal Siswa (Cek Nilai Mandiri)**: Siswa cukup memasukkan NISN atau nama untuk melihat rekap kehadiran, nilai tugas 1–5, nilai ASTS (PTS), nilai ASAJ (PAS), dan status KKM.
2. **Panel Guru (Manajemen Multi-Kelas)**:
   - Filter tab kelas dinamis (Kelas VIII A, VIII B, dsb).
   - Edit nilai siswa, tambah siswa, hapus siswa, dan tambah kelas baru.
   - Cetak format resmi analisis penilaian ASTS 1 sesuai standar sekolah.
3. **Database Cloud Supabase**: Terhubung real-time ke Supabase PostgreSQL database.
4. **PWA Mobile App**: Dapat di-install langsung di layar utama smartphone (Android & iPhone) tanpa melalui Play Store.
5. **Dukungan Spreadsheet**: Ekspor CSV format DataNilai dan impor baris data spreadsheet langsung.
